# وحید تیونینگ — Vahid Tuning

فروشگاه اختصاصی فارسی و راست‌چین تجهیزات **موتور تریل، اندرو و آفرود**، پیاده‌شده به‌صورت **قالب مستقل وردپرس + WooCommerce** و افزونه جداگانه برای ورود داده آزمایشی.

> **وضعیت:** کد فروشگاه و قالب آماده نصب است. انتشار عمومی مستلزم استقرار وردپرس، فعال‌سازی ووکامرس، تکمیل تنظیمات پرداخت و حمل‌ونقل، اتصال دامنه و اجرای تست‌های پذیرش است. تصاویر محصول فعلاً تصویرسازی اختصاصی هستند، نه عکس واقعی کالا.

## قابلیت‌های پیاده‌شده
- صفحه اصلی با طراحی «پیست شبانه»: تم تیره با نارنجی برند، خطوط توپوگرافی، بنر مورب، نوار متحرک دسته‌ها، چیدمان بنتو برای شش دسته، محصولات پویا و انیمیشن ظاهرشدن هنگام اسکرول (با رعایت کاهش حرکت)
- فارسی، راست‌چین، موبایل/تبلت/دسکتاپ، منوی موبایل، جستجوی کالا، دسترس‌پذیری پایه و کاهش حرکت برای کاربران حساس
- یکپارچگی واقعی WooCommerce: دسته‌بندی، آرشیو، مرتب‌سازی، فیلتر بازه قیمت، صفحه محصول، انتخاب سایز، سبد خرید، تسویه‌حساب، حساب کاربری، سفارش‌ها و موجودی
- کارت‌های اختصاصی محصول؛ تصاویر پیش‌فرض SVG خودمیزبان تا زمان بارگذاری عکس واقعی
- پشتیبانی از واحد «تومان» (IRT)، قیمت‌گذاری بدون اعشار و واحد مناسب
- ۱۸ محصول نمونه در ۶ دسته با SKU یکتا، قیمت و موجودی نمایشی؛ برخی محصولات دارای انتخاب سایز (variation)
- پنل سفارشی‌سازی برای بنر، نوار اطلاع‌رسانی، تلفن، آدرس، اینستاگرام و واتساپ
- بدون وابستگی به page builder یا کتابخانه JS شخص ثالث برای تعاملات سایت

## راه‌اندازی توسعه محلی
پیش‌نیاز: Docker Desktop / Docker Engine + Compose.

```bash
git clone https://github.com/SaeedTqpy/Vahidtuning.git
cd Vahidtuning
cp .env.example .env
# در فایل .env رمزهای محلی را تغییر بدهید.
docker compose up -d
```

مرورگر: **http://localhost:8080** (یا پورتی که در `WP_PORT` تنظیم شده است)

۱. نصب اولیه وردپرس را تکمیل کنید؛ زبان را **فارسی** قرار دهید.
۲. از «افزونه‌ها ← افزودن»، افزونه رسمی **WooCommerce** را نصب و فعال کنید. مراحل پایه راه‌اندازی فروشگاه را کامل کنید.
۳. در «نمایش ← پوسته‌ها»، پوسته **Vahid Tuning** را فعال کنید.
۴. در «افزونه‌ها»، افزونه **Vahid Tuning - Demo Catalog** را فعال کنید.
۵. در «ابزارها ← محصولات نمونه وحید تیونینگ» دکمه **ساخت محصولات نمونه** را بزنید.
۶. «تنظیمات ← پیوندهای یکتا» را روی «نام نوشته» قرار دهید و یک بار ذخیره کنید.
۷. «نمایش ← سفارشی‌سازی» برای متن بنر، اطلاعات تماس و شبکه‌های اجتماعی استفاده می‌شود.
۸. صفحات فروشگاه، سبد خرید، تسویه‌حساب و حساب کاربری را در «ووکامرس ← تنظیمات ← پیشرفته» بررسی کنید. ووکامرس معمولاً در راه‌اندازی آن‌ها را ایجاد می‌کند.

**توجه:** فایل‌های وردپرس و دیتابیس در Volume محلی Docker ذخیره می‌شوند. اجرای `docker compose down -v` کل دیتابیس و داده‌های محلی را حذف می‌کند.

## نصب روی هاست وردپرس موجود
پوشه `wp-content/themes/vahidtuning` را در محل متناظر هاست بارگذاری و فعال کنید.
پوشه `wp-content/plugins/vahidtuning-demo` صرفاً برای داده نمونه است. بعد از جایگزین‌کردن کالاها می‌توانید آن را غیرفعال کنید. برای نمایش صحیح تومان، قالب همچنان باید فعال بماند.

## مهم قبل از راه‌اندازی عمومی
- قیمت‌ها، موجودی، تصاویر، عنوان‌ها و توضیحات **آزمایشی** هستند و نباید به‌عنوان کالای آماده فروش واقعی منتشر شوند.
- درگاه پرداخت ایرانی سازگار با WooCommerce، حمل‌ونقل، مالیات، قوانین بازگشت کالا، حریم خصوصی و پیامک باید با سرویس‌دهنده‌های واقعی تنظیم شوند.
- SSL/TLS، بکاپ خودکار خارج از سرور، CDN/کش، WAF، ایمیل تراکنشی SMTP، مانیتورینگ، ضداسپم، سطوح دسترسی، امنیت ورود و اسکن به‌روزرسانی‌ها در **زیرساخت استقرار** الزامی‌اند.
- لایه WooCommerce، محاسبه سفارش، پرداخت و موجودی توسط خود WooCommerce انجام می‌شود و نباید با کد سفارشی غیراستاندارد دور زده شود.
- بارگذاری فونت Vazirmatn فعلاً از Google Fonts انجام می‌شود؛ برای بازار ایران در انتشار نهایی بهتر است فونت با رعایت مجوز OFL روی دامنه خودتان میزبانی شود.
- استانداردها و مجوزهای ایمنی (مثلاً ECE/DOT) را بدون مدارک معتبر برای کالاها ادعا نکنید.
- پیش از انتشار، تست خرید واقعی با درگاه sandbox، استرداد وجه، مالیات، فاکتور، موبایل و پیامک در محیط staging اجرا کنید.

## ساختار مخزن
```
wp-content/
  themes/vahidtuning/
    functions.php            # setup, hooks, customizer
    front-page.php           # homepage
    header.php / footer.php  # global shell
    page.php / index.php / search.php
    style.css                # design system + mobile + WooCommerce
    assets/css/night-trail*.css # Night Trail redesign layer (global + homepage)
    assets/js/storefront.js  # responsive menu/search/filters, scroll reveal
    assets/img/              # original SVG demo illustrations
    inc/woocommerce.php      # currency + single-product illustration fallback
    woocommerce/
      archive-product.php    # catalog and filters
      content-product.php    # product tile
  plugins/vahidtuning-demo/
    vahidtuning-demo.php     # idempotent demo importer
```

## توسعه و بررسی صحت
```bash
find wp-content -name '*.php' -print0 | xargs -0 -n1 php -l
node --check wp-content/themes/vahidtuning/assets/js/storefront.js
docker compose logs -f wordpress
```
